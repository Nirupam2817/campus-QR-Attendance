How The System Works

A seamless 3-step verification flow from classroom to gradebook

01
Instructor Starts Session

Faculty starts class with one click. Flask issues a cryptographically secure token valid for 5 minutes and displays a live QR code.

02
Student Scans with Mobile

Students scan the projected screen. The system validates login, session expiry, course enrollment, and duplicate records.

03
Instant Record & Analytics

Attendance is timestamped in SQLite. The faculty screen updates dynamically, and student dashboard percentages update in real time.
